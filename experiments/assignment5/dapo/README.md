# DAPO 补充实验正式源码

来源：2026-10-30 的独立 DAPO seed0 实验，完成 200 轮采样 / 800 次参数更新。

`code/dapo.py` 包含混合奖励组筛选、长度惩罚、样本标准差优势、非对称裁剪 loss 和 warmup；`code/train_dapo.py` 实现动态补采、冻结旧概率、四次更新、验证、同步审计及 W&B。`checkpoints.py` / `history.py` 管理优化器、随机状态和恢复谱系，区分有效更新与实际总开销。

固定 3-shot、OLMo-2-0425-1B、GSM8K 6400 / 1024；每轮筛选 32 个混合 G=8 组，最多考虑 256 个候选题。每次更新 64 回答，microbatch 8，按这 64 回答的有效 token 总数归一化。裁剪 `[0.8,1.28]`、LR `1e-6`、前 80 更新 warmup，没有初始参考 KL 惩罚。

训练服务器只保留最新完整恢复点；`checkpoint-policy.json` 明确不自动同步模型权重。`local_checkpoint_policy.py` 是当时切换检查点保留策略的兼容工具，其本地完整性记录不能充当远端模型备份回执。

`run_formal.py` 保留原部署的回执和锁检查；代码内的历史路径需按新环境配置。CPU 检查、依赖版本和发布边界见[总说明](../README.md)。这不是对原始 DAPO 论文所有模型、数据与训练设置的复现。
